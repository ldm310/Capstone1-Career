# 예시: demo/shopmall, 사람 eun

직접 만든 가짜 레포(실제 사람·서비스 아님)로 돌린 결과다.

- `bundle.json` 근거 묶음
- `packets.json` 점검 에이전트 입력
- `agent_output.json` 점검 에이전트 출력 **견본**(실제 LLM 출력이 아니라 손으로 쓴 것. 하나를 `unsure`로 둬서 정황 처리를 보여 줌)
- `verdicts.json`, `stat.json`
- `match.json`(공고 매칭 결과)은 이 브랜치에 넣지 않았다(2026-11-24). 실제 공고의 회사·제목·링크·요건 문장이 들어 있고, 폐지된 초기 LV 기준으로 낸 결과다. 원본은 보관 폴더 `~/Desktop/career-stat/career-stat-handoff/examples/shopmall-eun/`에 있다.
