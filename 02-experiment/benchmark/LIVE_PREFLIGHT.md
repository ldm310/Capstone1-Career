# Live 실행 확인 기록

- 사용자가 동일 Codex 계정, 인증 파일 1개, 자동 충전 OFF를 확인했다.
- 사용자가 제공한 사용량 화면에서 추가 크레딧 잔액은 0이었다.
- 로컬 프록시 설정에 공급자 유료 API 연결 항목은 없었다. OAuth 인증 파일은 1개이며 내용은 읽지 않았다.
- 프록시 request-retry=0, SDK max_retries=0. 한도/결제 오류 시 중단한다.
- 이는 계정 설정 확인이며 프록시의 모든 동작이나 실제 청구액을 보증하지 않는다.
- Gemini Free tier 확인은 아직 없다. 자동 전환하지 않는다.

## 첫 1명 시험

`runs/live-confirmed-smoke`에서 실제 모델 요청 1회 후 ValidationError로 중단했다.
입력 6606 / 출력 3069 토큰, 요청 56.91초. A만 완료, C 오류, B/D/E 미실행.
검증 실패한 최초 응답 원문을 저장하지 않아 구체적인 실패 필드는 사후 확인할 수 없다.

코드 점검에서 위험 항목의 정확한 ID 목록을 모델에 전달하지 않은 문제를 발견했다.
ID 목록과 필수 필드 안내를 추가하고 후속 실패의 원문/검증 오류를 로컬 호출 원장에 보존하도록 개선했다.
이 변경이 최초 오류의 원인이었다고 단정하지 않는다. 변경 후 테스트 35개 통과.
후속 시험은 기존 결과를 덮어쓰지 않고 `runs/live-confirmed-smoke-v2`에 저장한다.

## 해석 제한

합성 20명은 사람이 검토한 정답 자료가 아니다. 실제 모델을 호출해도 정확도 우승은 결정할 수 없다.
프롬프트 수정 전후 실행은 동일 조건의 반복으로 합치지 않는다.
원문 응답은 외부 공유/Git 포함 금지. 오류 호출도 사용량에 포함한다.
