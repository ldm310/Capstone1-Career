DB 선택 · 예시

핵심 통계는 이렇게 뽑힙니다

표를 이어 붙여(JOIN) 세는(COUNT) 쿼리 한 번이면 됩니다. 스키마는 확정 전 예시입니다.

FK가 연결을 지켜 주므로, 없는 공고를 가리키는 부문이나 없는 스킬을 가리키는 연결은 DB가 막습니다.
-- 조건에 맞는 공고에서 스킬별 등장 횟수
SELECT s.name, COUNT(*) AS cnt
FROM job_posting p
JOIN job_section   js ON js.posting_id = p.id
JOIN section_skill ss ON ss.section_id = js.id
JOIN skill         s  ON s.id = ss.skill_id
WHERE p.source = 'saramin'
  AND p.extra->>'employment_type' = '정규직'   -- 소스별 항목도 JSONB로 바로 조건에 사용
GROUP BY s.name
ORDER BY cnt DESC;
