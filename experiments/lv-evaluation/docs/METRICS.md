# 지표 정의

모든 정확도 지표의 평가 단위는 **고유 case_id**다. 반복 실행은 일관성 계산에만 사용하며 독립 표본 수에 더하지 않는다. 시스템 오류는 의미상 `confirmed_level=null`인 판정 보류와 분리한다.

| 지표 | 원시 분자 | 분모 |
| --- | --- | --- |
| 최종 LV 결과 일치율 | 완료 결과 중 기대 LV와 정확히 같은 사례 수 | 기대 답안이 있고 완료된 고유 사례 수 |
| 기준별 판정 일치율 | criterion status가 기대 상태와 같은 수 | 비교한 고유 사례의 기대 criterion 총수 |
| 과대/과소 인정 | 실제 LV ordinal이 기대보다 큰/작은 사례 수 | 비교 가능한 고유 사례 수(표에는 원시 건수 제공) |
| 근거 오류 | 존재하지 않거나 기준을 충분히 지지하지 않는 인용 수 | 사람이 검토한 인용 판단 수 |
| 판정 보류 | `confirmed_level=null`이고 `review_required=true`인 사례 수 | 비교 가능한 고유 사례 수 |
| 불필요한 보류 | 기대 LV는 있으나 판정 보류한 사례 수 | 비교 가능한 고유 사례 수 |
| 판정 범위(coverage) | `confirmed_level`이 null이 아닌 고유 사례 수 | 비교 가능한 고유 사례 수 |
| 반복 실행 일관성 | 모든 반복의 상태/LV/criteria가 같은 case-method 그룹 수 | 2회 이상 실행한 case-method 그룹 수 |
| 실행 실패율 | `system_error` 또는 `budget_exceeded` 실행 수 | 전체 실행 수 |
| 시간·호출·토큰·재시도 | 완료 실행의 기록값 합계/평균 | 표에 실행 수와 함께 기록 |
| 비용 | 공급자 사용량 × 사전 입력 단가 | 가격 설정이 없으면 N/A(0원으로 바꾸지 않음) |

합성 draft 예상 답안으로 계산한 일치율은 회귀 테스트 신호일 뿐 품질 추정치가 아니다. 근거의 의미를 사람이 검토하지 않은 데이터에서는 근거 오류를 N/A로 둔다.
