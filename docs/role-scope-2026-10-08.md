# 직무 범위: 데이터·백엔드

2026-10-08 사용자 결정: 우선 데이터와 백엔드 두 직무만 지원하고 이후 확장한다.

- 선택 가능한 직무는 `data`(데이터), `backend`(백엔드) 두 개다. 홈 안내, 목표 선택, 공고 필터, 체험 온보딩, 시장 체험, 과제와 스터디 예시에 반영한다.
- 데이터 경로는 SQL·Python → 데이터 저장·작업 연결 → 선택적 대용량 처리로 구성한다. 기존 데이터 엔지니어링 경로를 기반으로 하며 데이터 분석·사이언스의 별도 세부 트랙은 아직 제공하지 않는다.
- 백엔드 경로는 HTTP/API·SQL → DB·트랜잭션·입력 검증 → 프로젝트에 맞는 Spring Boot 또는 Node.js 선택 확장이다. 두 프레임워크를 모두 필수로 요구하지 않는다.
- 실제 공고는 제목에서 데이터 또는 백엔드 직무가 명시된 경우만 포함한다. AI/ML·프론트엔드·일반 Software Engineer를 백엔드로 임의 분류하지 않는다. 따라서 수집처에 해당 공고가 없으면 목록이 줄거나 비어 있을 수 있다.
- Java·Kotlin·Gradle·XML 파일을 GitHub 검사 범위에 포함하고 Java·Spring Boot·Node.js·REST API 관련 기술 탐지 패턴을 추가한다. 기존 최대 20개 파일 검사 한계는 유지된다. 기술 탐지는 실제 능력 인증이 아니다.
- 폐지된 직무 설정은 기본값 데이터로 표시하며 백엔드를 다시 선택할 수 있다. 기존 분석 자료·지원 기록·포인트는 삭제하지 않는다. 지원 범위 밖의 저장 공고는 현재 목록에서 숨기되 저장 자료를 일괄 삭제하지 않는다.
- LV 및 Low/Middle/High 확정 기준은 이번 직무 변경으로 새로 정의하지 않는다. 기준이 없는 기술은 기준 준비 중 안내를 유지한다. 실제 판정 대기와 명시적인 스터디 예시 체험 분리도 유지한다.

검증: 두 직무 선택·저장·재접속·학습 경로 연결, 미지원 직무 API 입력 거절, 공고 분류, 기존 공고·스터디·성장 화면 회귀 테스트.
