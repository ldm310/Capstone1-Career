## 검증

- 격리 PostgreSQL에서 크롤러 전체 94개 통과, skip 0. 기존 임베딩 회귀 18개 중 실제 API smoke 1개만 의도적 skip.
- 이후 추가한 마지막 페이지 회귀를 포함해 아카이브 전용 11개 테스트 통과.
- 본문 SHA-256·본문 길이·실제 파일 존재, 대학 PDF SHA-256·페이지 번호·추출 문자 합계를 전수 확인했다.
- Windows 줄바꿈 변환 때문에 실제 파일 바이트 해시가 달라지는 문제를 수정했다. 확보한 본문 파일도 LF로 정규화한 뒤 메타데이터 해시와 일치함을 확인했다.
- 디코딩 대체 문자 U+FFFD 0개. 원자료의 중복은 보존·식별하되 최종 통합 목록에서 출처 ID 중복을 제거했다.
- 유료 OCR·임베딩 API 호출 0회. 실제 접근 제한 우회·로그인 세션 사용·RDS 설치/적재는 수행하지 않았다.
