내 STAT 계산

기술별 LV를 목표 직무 기준으로 모아 “어느 단계에서 막히는 지원자인가”를 LLM 없이 규칙으로 계산

미정 핵심 기술 목록 · 선정 근거 (직무 기준표 작성 전) — 예시 N = 5

비교 · 평균 LV를 쓰면
(2 + 1 + 1 + 0 + 0) ÷ 5 = 0.8 (미확인 AWS = 0)
Docker LV0과 AWS 미확인이 같은 0 → 막힌 단계가 안 보임
막힌 단계 = 신뢰성 확보 (LV2)

과제 완성형 — 기능은 끝까지 만들지만 예외 검증 · 실제 활용 근거가 없음 · 신뢰성 확보(LV2)에서 막힘
설계 고민
평균 대신 단계별 도달률: 평균 LV 0.8(미확인을 0으로)은 Docker LV0과 AWS 미확인을 같은 0으로 보고 어디서 막혔는지를 감춤 → 도달률 80 · 60 · 20 · 0 · 0%는 ‘신뢰성 확보(LV2)에서 막힘’을 보여줌. 미확인은 분모에 넣어 미도달로 셈(빼면 LV0+가 4/4 = 100%로 부풀려짐) — 단, ‘못함’이 아니라 ‘근거 없음’으로 따로 표시. 수치는 모두 규칙 계산이고 LLM은 03 리포트 문장만 씀. 계산 방식 · 기준값 50% · 유형 이름은 제안(팀 확정 전).
