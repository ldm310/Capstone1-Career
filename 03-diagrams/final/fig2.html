설계 고민
자료를 통째로 LLM에 넘기지 않고 출처 · 버전 · 위치 · 원문 단위로 쪼갬 → 02가 인용이 원문에 실제로 있는지, 다른 버전 결과를 섞지 않았는지(LV0 ‘다른 버전 결과 불인정’)를 규칙으로 검사할 수 있음. 문서는 자기 서술이라 버전이 연결된 실행 결과(L0-03 · L2-04)와 활용 · 변경 기록(L3-02 ~ 05)은 GitHub 기록에서 직접 받고, 본인 기여는 신호만 붙임(commit 작성자만으로 확정 X).

목표 직무가 바뀌면 증거는 그대로 두고 직무 기준표만 다시 불러와 02부터 재평가 (그림 8)
