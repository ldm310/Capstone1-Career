설계 고민
평가 엔진은 순서가 고정된 Python 워크플로(C안)로 시작하고 Multi-agent · LangGraph는 초기 범위에서 제외 — 합성 실험(정확도 N/A)에서 C는 전체 검토(D)보다 LLM 호출 7 vs 14 · 시간 9.53초 vs 19.47초. 수치는 규칙이 계산하고 LLM은 해석 · 문장만. 남은 고민: 앱에 붙이는 방법(미정) — 별도 Python 서비스면 실험 코드를 이어 쓰지만 배포 단위가 2개, TypeScript 이식이면 앱 하나로 유지되지만 같은 판정이 나오는지 다시 검증해야 함.

레포에 남은 v2 범위 밖 코드(처리 미정 · 이 그림의 흐름에서 뺌): 옛 LV1~3 성장 과제 · 포인트 · 랭킹, 스터디 매칭 · 성장 포인트 화면 프로토타입
