## 2. 확정된 결정 (사용자가 직접 정함)

- **LV0~5 누적형**
  - 단계: LV0 기본 수행 · LV1 과제 완성 · LV2 신뢰성 확보 · LV3 실제 활용·변경 대응 · LV4 측정 기반 개선 · LV5 복합 문제 설계
  - 31개 조건 L0-01~L5-07, 단계별 개수 4/4/5/5/6/7
  - 조건 상태: 충족 / 미충족 / 근거 부족(미확인) / 충돌
  - "필수·선행 조건이 모두 충족된 최고 LV"를 반환한다. 근거가 없으면 '미확인'이며 LV0이 아니다.
  - 실제 활용 기록이 없으면 LV2에서 멈춘다(예: "확인 LV2 · 신뢰성 확보 — 실제 활용 기록 부족으로 LV3 미확인, 개선 실험 근거는 보존").
- **평가 엔진 = C안**
  - LLM 해석 + 규칙 판정을 기본으로 하고, 위험 항목만 추가 LLM으로 재검토한다.
  - 미해결이면 승급을 보류하고 추가 자료 요청이나 사람 검토로 넘긴다. 오판은 회귀 테스트에 추가한다.
  - 두 LLM이 동의해도 정답으로 보지 않는다.
  - 초기에는 Python 고정 워크플로로 만들고, Multi-agent·LangGraph는 도입하지 않는다.
  - 근거: A~E 5개 구조 비교 실험에서 C가 전체 검토(D)보다 시간·토큰이 적었다. **정확도 우승이 입증된 것은 아니다.**
