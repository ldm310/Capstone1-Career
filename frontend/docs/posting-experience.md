# 공고 기반 역량 체험

`/experience`는 로그인 없이 하나의 백엔드 채용공고 예시를 보여준다.
홈의 역량 체험하기와 공고 목록의 예시 진입 링크가 이 화면으로 연결된다.
예전 `/onboarding` 진입도 같은 화면으로 보낸다.

기존 공고 상세의 요약, 공고 내용/역량 분석 탭, 다각형 차트, 점 LV 툴팁을 공유한다.
검수된 역량 문장 6개의 점수를 카테고리별로 평균 내며, 기술명별 옛 LV나 Low/Middle/High 선택 화면을 쓰지 않는다.
예시의 경력 조건과 본문은 서로 일치시켰다. 지난 예시의 마감일을 재사용하지 않는다.

체험 점수는 고정된 UI 예시이고 로그인한 회원의 결과로 대체하지 않는다.
로그인, 자료 등록, 사용자별 LV 저장, 분석 API 호출 없이 렌더링된다.
RDS 설정이 없는 배포에서도 체험은 동작한다. 실제 분석은 내 자료로 분석하기에서 시작한다.
체험 공고를 실제 저장 공고로 남기지 않도록 저장 버튼을 숨긴다.

관련 검증: 비로그인 진입, 공고/분석 탭 분리, 정확한 LV 툴팁, 개인 API/변경 요청 없음,
320px와 390px 너비, 접근성, 기존 진입 주소 리다이렉트.
